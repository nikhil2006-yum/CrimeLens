# 🚔 CrimeLens

### Intelligent Conversational AI for Karnataka State Police Crime Database

CrimeLens is an AI-powered Retrieval-Augmented Generation (RAG) assistant that enables police personnel to interact with the Karnataka State Police Crime Database using natural language.

Instead of searching manually through multiple records, officers can simply ask questions and receive accurate, context-aware responses grounded in official crime records.

**Intelligent Conversational AI for KSP Crime Database**
